Zoho API Console (Source)

  1. Go to api-console.zoho.com and add a Server-based Application or Self-Client.
  2. Generate Code with required read-only scopes:
  3. Generate Client ID, Client Secret, and Refresh Token.

Google Cloud & DWD (Destination)

  1. In Google Cloud Console, create a Service Account & download JSON Key.
  2. Enable Domain-Wide Delegation (DWD).
  3. In Google Admin Console > Security > API Controls, authorize the Client ID with Directory, Gmail, Calendar, and Contacts scopes.
